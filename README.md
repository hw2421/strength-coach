# 力的秩序 · 力量训练知识库

一个可离线阅读的力量训练知识库单页应用，HTML/CSS/JS 全部内联，无外部依赖、无后端。

## 内容结构

- 43 篇主题条目，覆盖力训底层逻辑、深蹲 / 卧推 / 硬拉动作框架、弱点诊断、营养恢复、伤病排查与训练实践
- 卡点排查台：选择动作与失败现象，得到检查顺序与验证方法
- 搜索、收藏、已读进度与笔记，数据保存在浏览器本地（localStorage）

## 在线访问

启用 GitHub Pages 后访问：`https://hw2421.github.io/strength-coach/`

## 本地阅读

直接双击 `index.html` 即可，无需联网。收藏、进度与笔记仅存于当前浏览器，换设备或清理浏览器数据后可能丢失，可用「导出笔记备份」保存。

## 说明

本资料用于学习与训练决策，不代替临床检查与诊断。参考书目见页面内「参考材料」。
